The library is your home page after you sign in. It lists every deck you own, and the decks other people have shared with you.

## Your decks

Each row shows:

- **Deck**: the title. Select it to open the deck page.
- **Slides**: how many slides the deck has.
- **Last change**: the most recent change in the deck's activity log.
- **Sharing**: who can open the deck. It reads **Private**, **Anyone with the link**, or **N named viewers**.
- **Updated**: when the deck last changed.
- **▶ Present**: opens the deck in the player.

The number next to the title is the deck count.

## Search

Type in **Search decks** to filter the list by title. The search runs in your browser, so it only narrows the rows you already see.

## Create a deck

1. Select **+ New deck**.
2. Enter a **Title**.
3. Pick a **Template**. Each template sets the slide layouts, the outline and the chrome, such as the part tracker and the footer.
4. Pick a **Palette**. The preview shows two sample slides in the look you picked. A template that locks its palette greys this choice out.
5. Select **Create deck**. SlideWorks opens the new deck's page.

If the server refuses the deck, the dialog stays open and shows the message.

You can also ask a connected agent to make a deck. See [Connect an agent](/agents/connect/).

## Shared with you

Decks that another presenter has shared with you appear under **Shared with you**. The table shows the owner's name next to each deck.

Select **▶ Present** to open a shared deck in the player. Shared decks do not open on the deck page, and you can't present them from the presenter view or the phone remote. Only the owner can do that. See [Sharing](/ui/sharing/).

## When the library is empty

If you have no decks yet, the page says **No decks yet**. Create one with **+ New deck**, or ask a connected agent to make one.
